Getting Started

ShopBot is an AI-powered customer support automation platform designed specifically for e-commerce stores. Get up and running in just 30 minutes.

Prerequisites: Node.js 18+, MongoDB Atlas account, Shopify or WooCommerce store

Installation

1. Clone the Repository

git clone https://github.com/shopbot/shopbot-mvp.git
cd shopbot-mvp

2. Install Dependencies

npm install

3. Environment Setup

cp .env.example .env
# Edit .env with your configuration

4. Database Migration

npm run migrate

5. Start the Application

# Development
npm run dev

# Production
npm start

Configuration

Environment Variables

Variable Description Required
MONGODB_URI MongoDB connection string Yes
JWT_SECRET JWT signing secret Yes
SHOPIFY_APP_SECRET Shopify app secret key Optional

API Reference

Authentication

All API requests require authentication using JWT tokens.

Authorization: Bearer <your-jwt-token>

Conversations

Manage customer conversations and chat sessions.

GET /api/conversations
POST /api/conversations

Orders

Access and manage order information.

GET /api/orders/:id
PUT /api/orders/:id/status

Troubleshooting

Common Issues

  • MongoDB Connection Failed: Check your MONGODB_URI and network access
  • JWT Token Invalid: Ensure JWT_SECRET is properly configured
  • Platform Integration Error: Verify API keys and webhook URLs
